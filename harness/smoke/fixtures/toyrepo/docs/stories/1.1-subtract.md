# Story 1.1: subtract

## Status
Ready

## Story
As a toycalc user, I want a `subtract(a, b)` function, so that I can take one
integer from another.

## Files to touch
- `src/toycalc/calc.py`: add `subtract(a: int, b: int) -> int`.
- `src/toycalc/__init__.py`: export `subtract`.
- `tests/test_calc.py`: add the tests below.

## Acceptance criteria
1. `subtract(5, 3) == 2`.
2. `subtract(1, 4) == -3` (the result can be negative).
3. `from toycalc import subtract` works.

## Test plan
- `test_subtract_returns_difference`: AC 1.
- `test_subtract_can_go_negative`: AC 2.
- Both import from `toycalc`, which covers AC 3.

## Gate
`uv run pytest -q`, from the repository root.
